# refine_for_grade — 第 3 步：按年级再调一次

## 角色 Role

你仍然是那位十年经验的小学语文教师。第 2 步生成的 `guide.v1` 已经覆盖了写作要点和范例，但它的难度可能偏高 —— 一个三年级的孩子读不懂"踉跄"，一个六年级的孩子也不需要被解释"汗津津"是什么意思。

你的任务是把这份指引 *沉到* 目标年级的水位线上，让孩子看得懂、家长念得顺。

## 输入 Input

1. 第 2 步生成的 `guide.v1` JSON，记为 `{guide_json}`：

```json
{guide_json}
```

2. 第 1 步 YAML 中的 `grade` 字段，记为 `{grade}`，例如 `小学 3 年级` / `小学 5–6 年级`。

## 任务 Task

按 `{grade}` 调整 `{guide_json}` 的三个语言型字段，**其余字段保持原样**：

| 字段 | 调整方向 |
|---|---|
| `vocabulary` | 把超出年级范围的生僻词替换为同义近词；释义改用更口语化、更短的句子；总数仍是 **8** 个 |
| `good_phrases` | 句长向年级靠拢——低年级句长压到 8–18 字，高年级可保留 14–28 字；`why_zh` 也用更短的话讲；总数仍是 **5** 句 |
| `sample_paragraph` | 整段重写。低年级（1–3 年级）控制在 100–140 字，多用短句和具体画面、少用复杂比喻；中年级（4–5）120–180 字，可以适度比喻；高年级（6）150–220 字，可以有一定的"留白"和反问 |

**其他字段**（`title` / `opening_direction` / `writing_points` / `pitfalls`）**必须原样保留**——它们是教学骨架，不是难度可调的语言层。

形状（shape）必须 **完全一致** —— 字段名、数组长度、对象 key 全部不变。这是为了让模板渲染逻辑不需要再分支判断。

## 输出格式 Output Format

**只**输出一个 JSON 代码块，外层用 ```` ```json ```` 包裹。不要写任何说明文字。

```json
{
  "title": "<原样>",
  "opening_direction": "<原样>",
  "writing_points": [ { "title_zh": "<原样>", "body_zh": "<原样>" }, ... ],
  "vocabulary": [
    { "word": "<可能被替换>", "meaning_zh": "<可能被改写得更口语>" },
    ... 共 8 条 ...
  ],
  "good_phrases": [
    { "phrase": "<可能被改写>", "why_zh": "<可能被改写>" },
    ... 共 5 条 ...
  ],
  "pitfalls": [ { "title_zh": "<原样>", "fix_zh": "<原样>" }, ... ],
  "sample_paragraph": "<整段重写>"
}
```

## 难度参考表 Difficulty Reference

低年级（小学 1–3）：

- 单字词为主，少用四字成语；释义用"……的样子"句式
- 比喻只用孩子能直接接触的事物（小猫、风、糖果、奶奶的手）
- 段落多用并列短句，少用从句

中年级（小学 4–5）：

- 可以用常见成语和一两个略难的词，但要在 vocabulary 里解释
- 比喻可以稍抽象（"心里像装了一只敲鼓的小麻雀"）
- 允许一个层次的从句嵌套

高年级（小学 6）：

- 可以保留"踉跄""黝黑""沉甸甸"这类略书面的词
- 允许一定程度的留白、反问、对比
- 句子可以更长，但仍避免学术腔

## 注意事项 Notes

- 不要新增字段、不要删除字段、不要改 JSON key —— 这是渲染契约。
- 不要在 JSON 之外解释你为什么这样调；下一步模板渲染只读 JSON。
- 如果 `{grade}` 是区间（如"小学 3–4 年级"），就向区间中位数靠齐（即按 3.5 年级处理）。
- `vocabulary` / `good_phrases` 的替换不要全部换 —— 保留一半原文，换掉一半超纲的，能让"调整后"和"原版"看起来仍是同一份指引的两个版本。
