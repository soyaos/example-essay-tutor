# rendered — committed font-rendering evidence (APP-1058)

Artifacts produced by the E2E suite (`make e2e`) from the three Chinese
sample essays, through the **real** chain + renderers:

| File | What it is |
| --- | --- |
| `guide-N.html` | web template render (`templates/guide.html.tmpl`) |
| `guide-N.print.html` | print template render — the exact document the PDF is printed from |
| `guide-N.pdf` | A4 PDF printed by headless Chrome (`pkg/artifact.PDFRenderer`), CJK font subsets embedded |
| `guide-N.web.png` / `guide-N.print.png` | full-page Chrome screenshots taken during the glyph scan |

Samples: 1 = 常用字基线《难忘的一次劳动》, 2 = 生僻字《外婆的灶台》,
3 = 标点混排《我和 AI 下了一盘棋》.

These files are **regenerated by every test run** — do not edit by hand.
If templates or fixtures change, rerun `make e2e` and commit the diff in the
same change.
